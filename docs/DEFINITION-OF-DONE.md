# Definition of Done

A project is done only when all applicable evidence exists:

- Manifest reflects the delivered topology and scope.
- Source connections and parameters are documented without secrets.
- Refresh or query execution succeeds in the target mode.
- Model grain, keys, relationships, formats, descriptions, and measures are reviewed.
- Required RLS and OLS tests pass for representative identities.
- Report pages match their stated decisions and audiences.
- Accessibility checks cover alt text, tab order, contrast, titles, and keyboard behavior.
- Performance is measured against manifest thresholds.
- Static validators pass.
- Power BI Desktop opens, refreshes, saves, closes, and reopens the project cleanly.
- Target-environment deployment, parameterization, refresh, permissions, and rollback are tested.
- QA and release evidence are recorded under `docs/`.
